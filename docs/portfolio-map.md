## Publication standard

No repository is considered portfolio-ready merely because its README is polished. Source code, dependencies, data, credentials, screenshots and deployment configuration must be reviewed first.

Internal business data, credentials, personal records, private documents and institutional secrets must never be published. Public demonstrations should use synthetic or anonymized examples.
